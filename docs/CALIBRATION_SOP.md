# Calibration SOP

## Purpose

Calibration helps the app estimate on-screen visual acuity target size more responsibly. Without calibration, visual acuity output must be labeled as a near-screen screening estimate only.

## Supported Methods

- Standard card: use a standard card width of 85.6 mm.
- Ruler: use a clearly marked 50 mm ruler segment.

## Parent/User Instructions

1. Use the same device and browser that will run the test.
2. Clean the screen and set brightness to a comfortable, steady level.
3. Disable screen zoom or browser zoom if possible.
4. Open the calibration screen.
5. Select standard card or ruler.
6. Hold the physical card/ruler directly against the screen.
7. Adjust the on-screen bar until it exactly matches the physical reference width.
8. Save calibration.
9. Keep the device still during test setup.
10. Repeat calibration if the device, browser zoom, display scale, orientation, or screen changes.

## Brightness Instruction

Use a stable brightness setting. Avoid very dim screens, glare, reflections, or automatic brightness changes during testing.

## Viewing Distance Instruction

Use the app-specified test distance. If the child moves too close, too far, or cannot hold a stable distance, pause testing and mark the result incomplete or unreliable.

## Device Change Rule

Calibration is valid only for the calibrated device/browser/display setup. A new phone, tablet, laptop, external monitor, browser zoom setting, or display scaling change requires recalibration.

## Recalibration Rule

Recalibrate:

- Before clinical review sessions.
- After changing device orientation or screen zoom.
- After operating system display scaling changes.
- If measured target sizes look visibly wrong.
- At least once per staging/pilot testing day.

## Unreliable Result Criteria

Mark the result incomplete or unreliable if:

- Calibration is skipped and the user needs calibrated acuity.
- Parent cannot match the reference object accurately.
- The reference object is not a known size.
- Child is not at the required distance.
- The wrong eye may have been covered.
- Lighting/glare prevents reliable viewing.
- The child guesses, looks around the occluder, or does not understand the task.

## Metadata To Store

- Calibration method
- Reference width in millimeters
- Reference width in pixels
- Pixels per millimeter
- Estimated PPI
- Device pixel ratio
- Screen width and height
- Viewport width and height
- User agent/platform/device information
- Calibration timestamp
- Test distance used with each result

## Doctor Interpretation Note

Doctor review should treat calibrated acuity as screening support, not a clinical visual acuity measurement. Uncalibrated results are near-screen screening estimates only.

## Limitation

This calibration is user-assisted and not hardware-certified.
